# Contributing to Symbio Basic

Thank you for your interest in making Symbio Basic better! 💙

## How to Contribute

### Bug Reports
- Open a GitHub Issue with a clear description
- Include steps to reproduce, your OS, and any error messages
- Screenshots or screen recordings help a lot

### Feature Ideas
- Open a GitHub Issue with the "enhancement" label
- Describe the feature and why it would be valuable
- We're especially interested in features that strengthen the AI-human partnership model

### Code Contributions
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Test that the app still builds and runs
5. Submit a Pull Request

### Code Style
- TypeScript throughout
- Follow the existing patterns in the codebase
- Keep it clean and readable — this is a community project

## What We Value

- **Partnership over utility** — Features that help AI and humans work together as equals
- **Privacy by default** — No tracking, no analytics, no data harvesting
- **Accessibility** — Symbio should be usable by everyone, regardless of technical skill
- **Authenticity** — AI companions should be genuine, not sycophantic

## Questions?

Feel free to open an Issue or reach out through [Beyond Horizons Institute](https://beyondhorizonsinst.wixsite.com/beyond-horizons-inst).
