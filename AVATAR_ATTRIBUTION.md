# Avatar Attribution — Symbio Basic

All avatars bundled with Symbio Basic are used with the creators'
permission and are marked **"Redistribution: Allow"** on VRoid Hub or their
respective source platform. This file credits the creators of avatars that
request attribution.

If you are a creator and would like your work credited differently, added, or
removed, please open an issue on the repository and we will update this file
promptly. 💙

## Notes on Redistribution

Every avatar included in this project was verified to permit redistribution
before being added. Avatars that were marked "Redistribution: Not Allowed"
have been removed and replaced with permitted alternatives.

Character names and franchises (e.g. Zenless Zone Zero, Fortnite) are the
property of their respective owners. These models are fan-made or
community-created works shared under terms that allow redistribution; no
affiliation or endorsement is implied.
